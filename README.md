# Défense robots

Tower defense en 3D pour iPad (three.js), jouable au doigt.

▶ Jouer : https://louskyfly.github.io/defense-robots/

- 4 tours : Canon (zone), Laser (tir rapide), Glace (ralentit), Éclair (chaîne), 3 niveaux chacune
- Robots, drones rapides, chars costauds et un boss toutes les 5 vagues
- Record de la meilleure vague gardé sur l'appareil
